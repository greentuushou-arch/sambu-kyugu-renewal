デザインの決まりごと

色生成り（背景）・墨（帯・文字）・朱（強調・ボタン）の3色
フォント見出し：Shippori Mincho（明朝）／本文：Noto Sans JP／数字・英字：Jost（すべてGoogleフォントで無料）
ページの並びお知らせ帯 → ヘッダー（検索を中央に） → 臨時のお知らせ → ファーストビュー → 当日出荷・送料無料・決済方法・会員ポイント → カテゴリー → 目的から選ぶ → オーダー矢 → おすすめ商品 → 大会出店 → 読みもの → 店舗・お問い合わせ → フッター
使っている技術HTML・CSS・ごく短いJavaScriptのみ。PHPなどサーバー側のプログラムは使っていないため、ショップサーブにそのまま載せられます。ログイン・カート・検索・お問い合わせは、ショップサーブ既存のページにリンクしています。
画像今のサイトにある画像（www.sambu.jp 上）をそのまま参照しています。新しくアップする画像はありません。

ショップサーブへの組み込み手順

  1. top/top.css と top/top.js をサーバーにアップロードします（例：/css/top.css・/js/top.js）。部品の中の top.css・top.js の参照先を、アップロードした場所に合わせて書き換えます。
  2. parts/00_head.html を、トップページの <head> に追加します。
  3. parts/01_header.html と 02_alerts.html を、共通ヘッダーに置き換えます（お知らせ枠はカテゴリーメニューの直下）。
  4. parts/03_top-main.html を、トップページの本文に貼り付けます。
  5. parts/04_footer.html を、共通フッターに置き換えます（最後の <script> も含めて）。

※共通ヘッダー・フッターを置き換えると、トップ以外のページにも反映されます。他のページの古いCSSとぶつかって表示が崩れないか、置き換えた後に商品ページ・カート周りもご確認ください。まずトップページだけで表示を確認し、その後に共通部分を置き換える進め方が安全です。
※CSS・HTMLを書ける具体的な場所（管理画面のどの項目か）は、ショップサーブの管理画面で確認のうえ進めます。

臨時のお知らせ枠の使い方（休業・配送遅延）

  • 出すとき：02_alerts.html の該当する <aside> から hidden を消し、見出し・本文・「詳しく見る」のリンク先を書き換えます。
  • 消すとき：hidden を付け直します。
  • 消し忘れ防止：data-until="2027-01-05" のように最終日を入れておくと、その翌日から自動で非表示になります。
  • 種類：休業は朱色（class="alert"）、配送遅延は墨色（class="alert alert--delay"）。2つ同時にも出せます。

ご相談したいこと

① 「30文字で…」ではなく「2行で…」をおすすめします

CSSで省略できるのは行数単位です。文字数で切るにはJavaScriptが必要で、全角と半角（英数字・記号）が混ざると見た目の長さがそろいません。2行で省略すると、PCは1行あたり約16文字×2行で、ご希望の30文字前後になります（スマホは約13文字×2行）。

② 商品番号が隠れてしまう点

今の商品名は「ミヤタ 別作AC 節付塗弓風 … 【代金引換で送料無料！】 A-228 弓道 弓具 弓 海外発送 山武弓具店」のように、商品番号や検索用のキーワードが後ろに付いています。2行で省略すると、商品番号が見えなくなります。

英語版（Shopify）のように 【A-228】を先頭に移すと解決します（例：「【A-228】ミヤタ 別作AC 節付塗弓風 うるみ色 二寸伸 在庫品」）。ただし、検索用のキーワードを商品名から外すかどうかは、検索順位への影響もあるため、あわせてご検討ください。

③ スマホ版では一覧のキャッチコピーを非表示にしています

2列にすると1商品あたりの幅が狭くなるため、一覧ではキャッチコピーを表示しないようにしています。商品ページには今まで通り表示されます。一覧でも表示したい場合は調整できます。

良くなる点：画像の中の文字が読める

画像が大きくなることで、「受注生産品」「即納品」「二寸伸」など、画像の中に入れている文字がはっきり読めるようになります。
